# El Índice de Ceniza — Godot project

Entry scene: `src/ui/title_menu.tscn` (title screen), which opens
`src/world/province_map.tscn`. Content is JSON under `content/`; tests are
`tests/*_test.gd`. See the repository `README.md` and `docs/` for everything else.
The project started from GDQuest's Open RPG (MIT); the remaining parts it still uses
are credited in `CREDITS.md`.
