# Downloaded map and art options

Reviewed 2026-10-09. Original downloads are in `tools/local/art-options/`.
These are visual references / source packs, not extra playable campaign maps.
The authored province and its locations remain the campaign map.

Hero map markers use the existing licensed Claw & Blade character portraits,
matching the hero-selection controls. The prior unit sprites remain a fallback.
No Heroes III game assets have been imported. The new city interface uses actual
building ownership, daily yields, prerequisites and costs from the game economy.
